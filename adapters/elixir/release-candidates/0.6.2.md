# Elixir 0.6.2 release candidate — September 10, 2026

Prepared locally, not published or tagged. The registered `elixir-0.6.2`
worktree's branch `codex/elixir-0.6.2` starts from freshly fetched origin/main
`e35697a29275f8ec2cd32b87ef6911b938baedb9`. Its only changes are the Elixir
collaborative prose codec/tests, adapter version/changelog and these release

additive Elixir adapter release.

## Reason and distribution proposal

The public [Hex metadata](https://hex.pm/api/packages/relay_mark_elixir) reports
0.6.1 as the latest stable release. Its published tarball contains no
`lib/relay_mark/collaborative_prose.ex`. The private Git dependency used by the
Relay backend cannot authenticate in CI. The simplest supported fix is an
authorized 0.6.2 Hex publication, followed by the backend's existing open
lower-bound Hex dependency and an exact committed lock update. No CI credential,
deployment secret, or package fork is needed. Publication requires separate
approval; repository policy requires a verified main commit for the source tag.
